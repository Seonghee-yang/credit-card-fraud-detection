## 🎯 Analysis Objective

## 🚨 Problem
1. **극단적 클래스 불균형**

    정상 거래 99.89% vs 사기 거래 0.11% (Validation 기준 28,432건 vs 30건)
    
    → Accuracy만으로는 소수의 사기 거래를 제대로 탐지하고 있는지 판단하기 어렵습니다.

2. **비대칭적 손실 구조**
    
    FDS에서는 두 오류가 동일한 비용을 발생시키지 않습니다.
    - FN(미탐) : 실제 사기 거래를 정상으로 승인 → 직접적인 금융 손실 → 고비용
    - FP(오탐) : 정상 거래를 사기로 판단 → 고객 불편 및 운영 비용 발생→ 저비용
    
    F1-score는 두 오류의 균형을 평가하지만 **오류별 실제 비용 차이는 반영하지 못합니다.**


3. **미라벨 데이터 환경**

    실제 라벨 지정이 어려운 운영 환경 확장을 고려하면, 정상 거래의 패턴을 학습하고 이탈 거래를 탐지하는 비지도 이상탐지 접근이 적합합니다.



## 🔑 Key Findings
1. **Elliptic Envelope + 비용 최적화로 예상 손실 63.9%(920만원) 절감**

    Isolation Forest를 대조 모델로 두고, FN:FP 비용을 20:1로 설정하여 Total Cost가 최소가 되는 탐지 기준을 비교했습니다.

    |       | Isolation Forest | Elliptic Envelope |
    | ----- | ---------------: | ----------------: |
    | FN    |              13건 |            **5건** |
    | FP    |              28건 |            **4건** |
    | 예상 손실 |          1,440만원 |         **520만원** |


2. **F1 최적점과 비용 최적점은 일치하지 않음**
    
    F1-score가 가장 높은 지점과 Total Cost가 가장 낮은 지점은 달랐습니다.

    따라서 이번 프로젝트에서는 탐지 성능 자체보다 실제 비용을 최소화하는 기준을 운영 임계값으로 채택했습니다.
    
    *Note : 상세 비교는 아래 Cost-based Threshold Optimization 참고


3. **SHAP으로 모델의 판단 근거를 검증**

    SHAP 분석 결과, 모델의 주요 판단 변수는 V17, V14, V12로 나타났습니다.

    EDA에서 확인한 정상 분포 이탈 패턴과 일치하여, 모델이 데이터의 주요 이상 패턴 구조를 학습했다는 신뢰성을 검증하였습니다.



## 🔍 Analysis
### 01. EDA — 사기 거래는 어떤 구조를 가지고 있는가?
- 단일 변수의 상관계수는 |0.3| 이하로 선형 분리가 어려움
- 사기 거래가 정상 거래와 완전히 분리된 독립 군집을 형성하지 않음
- 정상 분포의 외곽 및 꼬리 영역으로 이탈하는 패턴 확인
- 일부 Feature에서 정상 분포의 경계를 벗어나는 패턴

→ 사기 거래가 독립된 군집보다 **정상 분포의 경계에서 이탈하는 형태**를 보였기 때문에,
> **정상 분포를 모델링하고 이탈 거래를 탐지하는 비지도 이상탐지 접근**을 적용했습니다.

### 02. Model Comparison - 어떤 이상탐지 모델이 적합한가?
| Model | Precision | Recall |  F1 |
| --------------------- | --------: | -------: | -------: |
| Isolation Forest | 0.38 | 0.57 | 0.45 |
| Autoencoder | 0.59 | 0.57 |  0.58 |
| **Elliptic Envelope** |  **0.83** | **0.83** | **0.83** |

#### Model Insight
- `Isolation Forest` : 축 직교 분할 방식의 특성상 정상과 사기가 겹치는 경계 구간을 충분히 분리하지 못해 상대적으로 오탐이 많았습니다.

- `Autoencoder` : 사기 표본이 극소수인 환경에서 정상 거래와 사기 거래의 복원 오차 분포가 충분히 분리되지 않아 사기를 "정상처럼" 복원하는 한계가 나타났습니다.

- `Elliptic Envelope`: 정상 거래의 공분산 구조를 기반으로 경계를 형성하여, 본 데이터에서 상대적으로 안정적인 이상치 탐지 성능을 보였습니다.

#### Scaling Comparison

스케일러 비교 : MinMax / Standard / Robust / None 조합을 비교한 결과, 스케일러에 따른 성능 차이가 크지 않았습니다.

PCA 변환 변수의 특성을 고려하여 불필요한 변환을 최소화하고 No-Scaling을 최종 선택했습니다.

## 03. ★ Cost-based Threshold Optimization — 어디에서 탐지를 멈출 것인가?
> F1-score가 가장 높은 지점이 실제 손실도 가장 적을까?

모델 선택 이후에는 탐지 임계값에 따라 달라지는 FN/FP 비용을 비교했습니다.

#### Cost Function
**$$\text{Total Cost} = (\text{FN} \times 20) + (\text{FP} \times 1)$$**

- FN : FP = 20 : 1
- 사기 미탐 비용을 오탐 비용의 20배로 가정
- FN 1건 = 100만원
- FP 1건 = 5만원

#### Threshold Optimization
Elliptic Envelope의 이상치 점수를 기준으로 탐지 임계값을 변화시키며 F1-score와 Total Cost를 비교했습니다.
- F1 최적점: FP 5건 / FN 5건, F1 = 0.83
- Cost 최적점: FP 4건 / FN 5건, F1 = 0.85

두 지점의 탐지 성능 차이는 크지 않았지만, 비용 관점에서는 Total Cost가 더 낮은 지점이 존재했습니다.

따라서 최종 운영 기준은 단순히 F1-score가 높은 지점이 아니라 **예상 손실을 최소화하는 임계값**으로 설정했습니다.


### 04. XAI(SHAP) - 모델은 왜 이 거래를 이상하다고 판단했는가?
#### Global Interpretation
SHAP Beeswarm Plot을 통해 전체 거래에서 모델의 판단에 가장 크게 기여하는 변수를 확인했습니다.
- 주요 변수는 **"V17 → V14 → V12"** 순으로 나타났으며, EDA에서 확인한 주요 이상 패턴과 일치했습니다.

#### Local Interpretation
개별 거래에 대해서는 Waterfall Plot을 활용하여 여러 변수가 어떻게 결합되어 이상치 점수에 영향을 미치는지 확인했습니다.
- 값이 낮을수록 사기 방향으로 기여하는 패턴도 EDA의 상관관계 방향성과 일치했습니다.

> → 단일 변수 하나가 아니라 여러 변수의 기여가 결합되어 거래의 이상 여부를 판단하고 있음을 확인했습니다.


## 🚦 Operational Strategy : 위험도 기반 3단계 대응 체계
Elliptic Envelope의 이상치 스코어를 운영 관점의 위험도로 구분하여 탐지 결과를 대응 단계로 연결했습니다.

| 위험도 | 대응 | 실제 분포 |
| :--- | :--- | :--- |
| **High Risk** | 즉시 차단 + 관제팀 알림 | 사기 거래의 83.33%가 집중됨 |
| **Medium Risk** | 추가 인증(OTP 등) 후 승인 여부 결정 | 정상/사기 모두 0%대로 매우 낮은 비중 |
| **Low Risk** | 정상 승인 | 정상 거래의 99.98%가 이 구간에 안전하게 분류 |


> 모든 이상거래를 일괄 차단하는 대신 위험도에 따라 대응 수준을 차등화하여,**탐지 성능과 고객 경험 사이의 균형을 고려한 FDS 운영 구조**를 제안하였습니다.

## 🧠 What I Learned
모델 성능을 비교하면서 높은 F1-score를 얻는 것과 실제 운영에 적합한 모델을 선택하는 것은 다른 문제라는 점을 확인했습니다.

실제 FDS에서는 사기를 놓치는 FN과 정상 거래를 잘못 차단하는 FP의 비용이 다르기 때문에, **F1-score만으로 모델과 탐지 기준을 결정하는 데 한계가 있다고 판단했습니다.**

이에 FN/FP의 상대적 비용을 반영한 **Cost-based Decision Framework**를 추가적인 평가 기준으로 설정하고, 모델의 탐지 성능과 예상 손실을 함께 비교했습니다.

또한 SHAP을 활용하여 모델의 판단 근거를 확인함으로써, 모델 성능뿐 아니라 왜 그렇게 판단했는지 설명하는 과정도 중요하다는 점을 배웠습니다.

결과적으로 이상거래 탐지를 단순한 "사기 탐지 문제"에서 "금융 손실을 최소화하기 위한 의사결정 문제"로 확장하여 바라볼 수 있었습니다.

## ⚠️ Limitations
- 본 프로젝트에서는 Validation 데이터를 활용하여 모델 성능 및 탐지 임계값을 검증했기 때문에, 완전히 독립적인 비지도 학습 환경에서의 운영 성능을 그대로 의미하지는 않습니다.
- 비용 가중치(FN:FP = 20:1)와 건당 피해액은 실제 금융기관의 운영 데이터가 아닌 가정값이며, 실제 적용 시 금융기관의 손실 구조와 운영 비용을 기반으로 재산정해야 합니다.
- 과거 데이터를 기반으로 분석했기 때문에 실제 운영 환경에서는 Data Drift 및 새로운 사기 패턴에 대한 지속적인 모니터링과 재학습이 필요합니다.
- 실제 FDS 적용을 위해서는 실시간 탐지 지연시간, 관제 인력, 추가 인증 성공률, 고객 이탈 등 운영 환경의 추가 비용과 제약 조건을 함께 검증할 필요가 있습니다.
